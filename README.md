# Gemini Reply Generator - Chrome Extension

🤖 Auto-generate professional replies and responses using Google's free Gemini API!

## Features

✨ **Smart Reply Generation**
- Analyzes comments and reviews automatically
- Generates contextual, professional responses
- Supports multiple tone styles (Professional, Friendly, Casual, Formal)

🔐 **Secure & Private**
- API key stored locally in Chrome storage
- No data sent to third-party servers
- Works completely offline after configuration

⚡ **Easy to Use**
- One-click reply generation on any website
- Edit generated replies before posting
- Minimal configuration required

🌐 **Universal Compatibility**
- Works on Google Maps reviews
- Compatible with comment sections across the web
- Auto-detects reply fields

## Installation

### Step 1: Get a Free Gemini API Key
1. Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Click "Create API Key"
3. Copy your API key

### Step 2: Install the Extension
1. Clone this repository:
   ```bash
   git clone https://github.com/vibhubhasinug18-bot/gemini-reply-extension.git
   ```

2. Open Chrome and navigate to `chrome://extensions/`

3. Enable **Developer mode** (top right corner)

4. Click **Load unpacked**

5. Select the `gemini-reply-extension` folder

### Step 3: Configure API Key
1. Click the extension icon in your Chrome toolbar
2. Paste your Gemini API key in the input field
3. Click **Save API Key**
4. Optionally adjust your preferred tone and language in Settings

## Usage

1. Navigate to any website with comment/reply fields
2. Click the **🧠 Generate Reply** button that appears near reply fields
3. Wait for the AI to generate a response based on the comment
4. Edit the generated reply if needed
5. Post your reply!

## How It Works

1. **Content Script** (`content.js`)
   - Automatically injects "Generate Reply" buttons on websites
   - Detects reply/comment text areas
   - Captures the comment text and context

2. **Background Service Worker** (`background.js`)
   - Communicates with Google's Gemini API
   - Generates intelligent responses
   - Handles API calls securely

3. **Popup UI** (`popup.html`/`popup.js`)
   - Quick access to API key management
   - Extension settings and status
   - API connection testing

4. **Options Page** (`options.html`)
   - Detailed settings management
   - Tone and language preferences
   - Secure key storage

## Troubleshooting

### "API Key not configured" error
- Open the extension popup
- Enter your Gemini API key
- Click "Save API Key"
- Test the connection with "Test API" button

### "Generate Reply" button not appearing
- Refresh the webpage
- Check that the extension is enabled
- Try on a different website with reply fields

### Generated replies seem generic
- The extension generates replies based on comment text
- Try adjusting the tone preference in settings
- Make sure you have sufficient context in the comment
